2. Penawaran Opsi Rekonstruksi Kontrak

Mengingat tingginya estimasi biaya operasional (OPEX) di atas, nilai kontrak saat ini tidak rasional untuk dilanjutkan apabila tidak ada restrukturisasi pendanaan. Berikut 3 opsi penyesuaian yang ditawarkan:

OPSI A: Skema "Laporan Statis" (Penyesuaian Ruang Lingkup)

Penghapusan Dashboard & Server: Membatalkan pembuatan portal website realtime. Scraping dilakukan manual via perangkat lokal (Server Cloud ditiadakan).
