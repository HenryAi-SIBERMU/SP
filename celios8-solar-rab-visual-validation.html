3. Keterangan Detail

Building Insights ($0.005/request)

Endpoint: GET /v1/buildingInsights:findClosest

40+ Fields yang Didapat (Level 1-4):

  • Level 1: name, center, boundingBox, imageryDate, imageryQuality, postalCode, administrativeArea, statisticalArea, regionCode
  • Level 2 (Solar Potential): maxArrayPanelsCount, maxArrayAreaMeters2, maxSunshineHoursPerYear, carbonOffsetFactorKgPerMwh, panelCapacityWatts (400W), panelHeightMeters (1.879m), panelWidthMeters (1.045m), panelLifetimeYears (20)
  • Level 3 (Roof Stats): wholeRoofStats, buildingStats, roofSegmentStats (pitchDegrees, azimuthDegrees, stats per segment, center, boundingBox, planeHeightAtCenterMeters)
  • Level 3 (Panel Configs): solarPanelConfigs (multiple scenarios), solarPanels (center, orientation, yearlyEnergyDcKwh, segmentIndex)
  • Level 2 (Detected Arrays): detectionStatus, latestCaptureDate (included via parameter additionalInsights=DETECTED_ARRAYS)

Data Layers ($0.025/layer)

Endpoint: GET /v1/dataLayers:get

3 Layers yang Diambil (GeoTIFF format):

  • RGB Imagery: Foto satelit aerial - validasi visual kondisi atap real
  • Mask: Binary mask atap vs non-atap - konfirmasi boundary detection akurat
  • DSM: Peta ketinggian 3D - cek elevasi & identifikasi obstruksi

Output Data

  • Total Data Fields: 40+ fields × 1,415 lokasi = 56,600+ data points
  • Visual Validation Rasters: 3 layers × 1,415 lokasi = 4,245 raster files
  • Grand Total Output: ~60,000+ data artifacts

Asumsi & Notes

  • Kurs: $1 = Rp 15,800 (2 September 2026)
  • Buffer 20%: Cadangan untuk requery jika ada error, timeout, atau kualitas rendah
  • PPN 11%: Pajak untuk transaksi internasional (jika dikenakan)
  • Target Lokasi: 1,415 dari framework - belum semua tervalidasi (actual: 1,089 = 77%)
  • Resolusi Default: 0.25m pixel size (high-res), radius 50m per lokasi
  • Quality Level: HIGH (imagery quality filter)
